## 3. Type + palette (differs from every sibling and every LESSONS site)
- **Display:** Gloock (high-contrast serif). Body: **Schibsted Grotesk**.
  Devanagari sub-line: **Tiro Devanagari Marathi**.
  (Not used by any sibling; none of the banned faces.)
- **Five hex values:**
  - `--blush  #EFE7DD` — page ground (warm pink-tinged limewash)
  - `--ink    #1E1B1A` — text, primary buttons, dark build section
  - `--brass  #B5832E` — THE signature highlight: seam flute, numbers, step marker, swatch
  - `--slate  #2B3A4A` — deep slate-blue blocks (reviews, find-us)
  - `--mist   #E3D4C4` — soft sand tint for section/build blocks
  Supporting: `--muted #5B5248`, `--line #D7C8B0`, `--paper #F7F1E6`.
  Buttons: primary = ink bg + white text (AA ok); on dark blocks = brass bg + ink text
  (AA ok). Focus outline = brass.

### Why it differs
- Fonts: siblings use Fraunces, Bricolage, Young Serif, Marcellus, Zilla Slab, Instrument
  Serif, Rozha One (display) / Instrument Sans, Figtree, Hanken, Mulish, Karla, Mukta
  (body). Gloock + Schibsted Grotesk are new.
- Palette: the folder is dominated by terracotta/rust reds (#B5461B, #9C3B2E, #E07A3F,
  #C2451F) and dark plum/espresso/green inks. This one is ink + **brass/ochre** on a
  **blush** ground with a **slate-blue** dark block — no terracotta as the accent.

## 4. Signature move
A **reeded-glass flute** — a row of thin vertical half-round ribs in brass — runs along
every section seam (replacing the old Awadhi-arch domes) and reappears as the one strip
of ornament. Fluting is the thing a visitor would describe: "the one with the brass
reeding." The single animated moment stays the 3D kitchen build on scroll.

### The four 3D finishes — ASSUMED, confirm with client
No photos sampled, so these are plausible laminates that suit the palette:
1. **Ink graphite** (matte near-black) `#23201D`
2. **Blush plaster** (pale matte shutter) `#E3D4C4`
3. **Slate-blue gloss** `#2B3A4A`
4. **Reeded oak** (natural wood) — procedural woodgrain
Brass is hardware/highlight only, not a shutter finish.
